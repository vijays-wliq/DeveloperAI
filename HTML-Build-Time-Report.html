How long it takes Claude Code to build the full HTML site (global setup + all pages) with Skill 1 · updated 18 Nov 2026

Updated with a real, measured build. A recent test project of 80+ pages was built end to end in about 8 hours at most, using Claude Code with PROJECT-BOOTSTRAP.md and the skills. The earlier figures in this report (20–38 h for a 15-page site) were estimates made before any real build and were far too high, so they have been replaced. The 80+ page figure is measured. 2. Why it is this fast

  • The design system is built once, up front. Tokens, vendor.css, global.html and the project CLAUDE.md are done in the first phases. After that every page reuses them, so nothing is re-decided per page.
  • Most sections are reused. On a large site the same headers, cards, CTAs and layouts repeat across many pages. A reused section takes minutes, not a fresh build.
  • Fixed rules remove back-and-forth. Breakpoints, naming, animation attributes and the delivery checklist are already decided in the bootstrap, so Claude does not stop to ask.
  • Global setup is a one-time cost. It takes about the same time for 5 pages or 80, so the per-page cost drops as the site grows.

5. What makes it faster or slower

Slower
  • Figma link fails → PDF only: values are measured instead of read, so extraction and corrections take longer.
  • Inconsistent design (many one-off sizes, every section different): fewer reused sections.
  • Heavy animation (timelines, pinning, 3D) or custom interactions.
  • Slow approvals: Claude stops at the TOKENS gate and waits. Calendar time grows, build time does not.
  • Big feedback changes after pages are built. A full feedback round is not included in the 8 h.
Faster
  • The designer used Figma variables and styles, so tokens come out almost exact.
  • A consistent design system, so more sections are reused.
  • Real copy and images are ready, so there is no placeholder rework.
  • You review each page as it finishes instead of all at the end.

6. What changed from the earlier report

The earlier version estimated 20–38 h of Claude time for a 15-page site (8–15 min per new section), plus 8–14 h of your time over 5–8 days. Those numbers were written before any real build. The first measured build did 80+ pages in about 8 hours, roughly 5× the pages in a fraction of the estimated time. The main gap was how much the shared global setup and section reuse speed up every page after the first few.

Long builds can still run over more than one Claude session. Each new session re-reads CLAUDE.md and global.html first, which takes a few minutes and is included in the measured time.
